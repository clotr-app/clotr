# Clotr 1.6.1 in detail

- Clotr now reads national ID numbers from Ireland (PPS numbers) and New Zealand (IRD numbers after their label, and NHI numbers), and from Brazil (CPF and CNPJ), India (PAN, after its label), France, the Netherlands, Poland, Italy, Germany (tax ID), Singapore, South Africa, Korea, Japan and China, the others checked by their own check digit, letter or birth date.
- Clotr catches more access tokens by their own start, with no label needed, including Google, Microsoft Entra, Azure DevOps, Docker Hub, Notion, Airtable, Bitbucket, Terraform Cloud, Doppler, Square, LangSmith and Pinecone tokens.
- A key wrapped onto indented, quoted or YAML folded lines, or broken right after its start like "ghp_", is found and covered whole. So is a key URL-encoded inside a link, and a password in a connection string with a driver scheme like postgresql+psycopg2.
- A token or password written after a sign-in scheme word, like "token: Bearer …" or after Basic, OAuth or Token, is found and covered whole. Real passwords that only look a little like code, such as a dotted passphrase or a name with brackets in it, are no longer skipped, while type names, function calls and variable names in code stay quiet.
- A recovery phrase is found inside an everyday sentence and in JSON arrays, lists and quoted replies, and long everyday word lists are no longer read as one.
- In a paste over 40,000 characters, a recovery phrase or a list of backup codes is still found when the paste is split for checking between it and its label, and checking takes no longer.
- Hide it and Clot this leak change a saved word only where it stands as a word, cover every ID a saved format finds, and hide what rides inside a link before cleaning it. A saved detail fixed in the middle of a message still warns.
- Hide it also hides each other copy of what it found, written another way in the same message: encoded inside a link, quoted in JSON, in an email's raw source, or right after an escape like "%20". A card or ID number encoded twice inside a link, or sent in a form or web request, is found too.
- Fewer false alarms: date-times, web log lines, git hashes, version and machine numbers, order and part numbers, settings and flags under password labels, lookup and page keys under token labels, and code names that look like hosts or emails.
- A typical message is checked in about four fifths of the time it took in 1.6.0, even with the new checks.
- A message that's still in the box, with more typed after it, no longer counts as sent, and a send waits for a pasted picture to reach the page so the two go together.
- Clotr checks a draft that wasn't typed in this tab when you click Send.
- Clotr says when an attached file is locked, damaged or too large to check, and reads more PDF and Office files correctly.
- Is this a scam? counts cheap web endings, link shorteners and links with a path, and shows the phone line for toll-free numbers too.
- Vault and helper pages lock when the PIN window ends, open again once the PIN is entered, and keep what you typed until the save is confirmed.
- What Clotr stores says what Clotr can reach now and hides the PIN record in its raw data.
- The popup's "Today" follows the popup's language, and Spanish caught-item lines lose a stray English article.
- In Firefox, a copy installed from addons.mozilla.org no longer wakes every minute to check its own files for updates.
- The toolbar count refreshes every half hour again after the browser starts, and old history is pruned then.
