# Engine rule reference

Engine version: 1.6.0

This table describes every built-in rule in `extension/patterns.js`. Vault and team rules are made from details the
person or organization chose to save, so their matches depend on those settings. Examples are invented shapes, not
working credentials or anyone's personal details. A format match does not prove that a credential is active.

For text longer than 40 KiB, `detect()` checks 40 KiB windows with an 8 KiB overlap. Each match is mapped back to
the original text. PEM private-key blocks up to 64 KiB get a bounded key-only pass if a window splits them; a
larger block is marked incomplete. The returned array has `.truncated === true` if the shared time, work or key
limit stops coverage; a caller should read that flag before filtering the results.

Wrapped credentials are also read across token line breaks inside indented YAML literal blocks. Cover it masks the
original span from the first token character through the last, including the breaks and indentation between pieces.
