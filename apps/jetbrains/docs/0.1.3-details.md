# Clotr for JetBrains IDEs 0.1.3 in detail

0.1.3 moves the plugin from engine 1.6.1 to 1.6.4 and fixes the clipboard check, the secret-file note and the ignore
file. Every value below is made up. The engine's own notes are in `apps/engine/docs/1.6.2-details.md`,
`1.6.3-details.md` and `1.6.4-details.md`, and this page says only how they show up in the IDE.

## Known issues

- A path under a camelCase setting gets a password warning, like `authToken: /run/secrets/db_password`. 0.1.2 is quiet
  on that line but warns on the same path under `auth_token:`.
- A plain number after a login code and "and", ", and" or "or" is read as a second code, so
  `the login code is 482913 and 551234.` gets two warnings where 0.1.2 gives one.
- A name under a dotted password setting in backticks, like `` set `db.password.value: orders-db` before deploy ``,
  gets a password warning. 0.1.2 is quiet there.
- A file over about 64 KB still stops partway in the IDE, since the engine runs without a compiler there. Clotr marks
  that file as not fully checked, as 0.1.2 does.
- The plugin now remembers whether Git ignores a secret file until a `.gitignore` on its path changes. An edit that
  keeps the file's size and lands within one clock tick of the last check isn't seen until the next change. 0.1.2
  read the files every time, so it doesn't have this.
- A key run into a letter or digit, like a key with a word stuck to its end, gets no warning. 0.1.2 does the same.

## What's found now that wasn't

These are credentials, so they show with the default settings.

- A password with a digit and a symbol under a camelCase name in YAML, JSON or XML, like `dbPassword: Wibble#42door`
  or `<dbPassword>Fennel!8842</dbPassword>`, and one under a name ending in Value, Ref or Arn, like
  `<SecretValue>Maple!2093x</SecretValue>`.
- A password one level under its name in YAML, like a CloudFormation parameter's `Default:` under `DbPassword:`, and a
  Secrets Manager password written as `SecretString=…`, `SecretString: …` or `"SecretString":"…"`.
- A password in a link with a login, like `smb://sam:hunter2!@nas.wibblecorp.io/share` or
  `ssh://deploy:wibble99@files.wibblecorp.io`, as a connection string. 0.1.2 missed these or warned only on the host or
  IP after the `@`. With a stand-in password, like `postgres://deploy:your_password@build-01.corp/share`, the warning
  stays on the host.
- Tokens in 19 more formats with no label in front, a key after `sessionKey:` or `authKey:`, a JWK with a brace in a
  quoted value, and secret webhook links for Teams, IFTTT and Zapier. A Google Chat link's token, which 0.1.2 read as
  a password, now reads as a token.
- A typed password that only sounds made up, like `password: example123!`, one under its own `.value`, like
  `db.password.value=maple_2093`, and a login code in quotes before its name, like `'482913' is my verification code`.

## Fewer false alarms

- Stand-in keys, like `key = sk_live_fedcba9876543210fedcba9876543210`, and a key block that's only `...`.
- A key file's path, like `apiKey: ./certs/server.pem`, a note under a password's ref name, like
  `password_ref: prod database password`, and a Secrets Manager ARN.
- A setting in backticks in a sentence, like `secret: true`. A one-word password in backticks, like
  `password: sunshine`, is quiet now too, where 0.1.2 warned.
- The `Thanks!` in `I forgot what my password is. Thanks!` and a dated line like
  `backup codes are not working since 2024`.
- An order number shaped like a card, like `Order number: 4111111111111111`. The same number after a card word still
  warns.

## With personal details on

- ID and tax numbers from 19 more European countries are found after their label, like a Danish CPR number.
- A phone number spelled with `nought`, `naught` or `ninty`, or with a spaced hyphen between number words, is found
  whole.
- Fewer warnings on everyday numbers, like a booking number in a message about dates.

## Check my clipboard and Check selection

- The dialog shows less of each found value. A password or private key shows only dots, where 0.1.2 showed its ends,
  like `Fenn…or`. Anything else shows at most two characters at each end, so a made-up AWS key that 0.1.2 showed as
  `AKIA…3N` shows as `AK…3N`.
- When a check runs out of time, Copy a cleaned version checks the rest of the text before it copies. It goes on from
  where the first check stopped instead of reading the whole text again, and copies nothing if it can't finish. 0.1.2
  covered only what the first check found and copied the rest as it was, so a key past the cut went out.

## Secret files and ignore rules

- A folders-only rule like `.env/` in `.gitignore` no longer counts as ignoring a `.env` file, so the note offering to
  add it to `.gitignore` shows, as Git would read the rule.
- A value that crosses a line break in a CRLF file gets the same `.clotrignore` fingerprint as Guard gives it, so
  Ignore this one works the same in both.
- A `.clotrignore` of exactly 8,192 lines that ends in a newline is read. 0.1.2 threw it out.
- Each check of a secret file reads the `.gitignore` files on its path only when one of them changed.

## Speed

- A file of 5,000 blank lines is checked in under half a second and finishes. 0.1.2 took 22 seconds with LF line
  endings and 91 with CRLF, and stopped partway.

## Look and source

- The icon's corner mark is the same steel disc as the VS Code extension's, with an IDE window inside.
- The Kotlin source is split into folders by what each part does (the engine bridge, open files, the clipboard check,
  ignore files, secret files, settings and Guard setup), with a map in `src/README.md`. Its actions, settings and
  saved data are the same as 0.1.2's.
