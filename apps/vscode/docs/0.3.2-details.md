# Clotr for VS Code 0.3.2 in detail

Everything here was checked against 0.3.1 with made-up values.

## Guard

- The Guard inside the extension is 0.1.4, up from 0.1.3. It's the same as the `clotr-guard` 0.1.4 package on npm,
  apart from one `"private": true` line in its package.json. Guard's own changes are in
  `apps/guard/docs/0.1.4-details.md`.
- The cost of Guard's new rename check is that a command that sets up an alias, a function or `hash -p` and also
  copies the example env file is stopped, like `alias ll='ls -la'; cp .env.example .env`. 0.3.1 runs it.
- The build reads Guard's list of files from Guard's package.json, so the extension carries the same files npm does.

## Guard hooks after an update

- When 0.3.2 starts for the first time after an update, Clotr finds the Guard hooks it set up that still name the old
  version's folder. It sets each one up again with the new Guard and the options it had, like its lowest severity, and
  doesn't ask. 0.3.1 asked "Clotr Guard moved since the last update. Set it up again?" instead, and until you said yes
  the hooks kept the old Guard.
- Hooks that aren't Clotr's, and settings you added by hand, stay as they were. An assistant with no Clotr hooks
  doesn't get any.
- If one assistant's hooks have two different sets of options, Clotr can't tell which you meant, so it asks.
- Cline's hooks don't run on Windows, so there they're left alone.
- If Windows refuses to replace a settings file, say because a second window has it open, Clotr tries again 4 times
  over about 1.5 s. If it still fails, it asks on every start until Guard is set up again.
- In a workspace you haven't trusted, the quiet setup always uses the Guard inside the extension and never looks for
  one through npm, so nothing in the workspace can run.
- Updating from 0.3.1 was run with 0.3.1's own Guard setting up Claude Code, Codex, Cursor, Gemini and Windsurf in a
  made-up home. 0.3.2 moved all 5 to its own folder with no question, and Codex kept its `high` setting.

## The engine

- The engine inside the extension is 1.6.4, up from 1.6.1. Its changes are in `apps/engine/docs/1.6.2-details.md`,
  `1.6.3-details.md` and `1.6.4-details.md`.
- In an open file these now get a warning, which 0.3.1 missed:
  - `share: smb://sam:hunter2!@nas.wibblecorp.io/share` and an `ssh://deploy:…@` link, as a connection string
  - `dbPassword: Wibble#42door`
  - `'482913' is my verification code`
  - `password: example123!` and `db.password.value=maple_2093`
  - `sessionKey: 9fQ2xLm7Rt4vKp8Wz3Yb6Nc1`
- These are quiet now, where 0.3.1 warned: `` `secret: true` `` in a sentence and `password_ref: prod database
  password`.
- Both versions stay quiet on `adminPassword: ^2.3.1`, `icon@2x.png` and a `users.noreply.github.com` address.
- `apiKey: ./certs/server.pem` still gets a warning in a file when another line follows it, as in 0.3.1. The engine
  is only quiet on it at the end of the text.

## Open files

- Closing a file clears its warnings from Problems, the Clotr view and the status bar. 0.3.1 read the close event the
  wrong way, so they stayed until the window reloaded.
- "Ignore this occurrence" ends when its file closes. In 0.3.1 it lasted until the window reloaded.

## Settings

- `clotr.skipList` patterns are matched by the same bounded matcher Guard uses. The made-up pattern `*a*a…*b`, with
  16 `*a` pairs, held up a file with a long name of a's for 157 s in 0.3.1. It takes 0.2 s in 0.3.2.
- With `clotr.personalDetailsInFiles` off, Clotr marks only cards, bank numbers and keys. 0.3.1 still marked a
  driver's licence, an insurance member number, a medical record number and an IP address, because it went by words
  in the kind's name.

## Looks and the README

- The icon's corner mark is a steel disc with brackets.
- The README asks teams using Clotr at work to add themselves to `ADOPTERS.md`.

## The code

- `extension.js` was one long file. It now starts the extension and leaves the work to files in `src/`, grouped by
  what they do, like `src/open-files/` and `src/guard-setup/`, with a README map. Every command, setting and message
  is the same, and package.json differs from 0.3.1's only in its version.
- The packed extension has 92 files, up from 19. The new ones are `src/` and Guard 0.1.4's own files, which are split
  the same way.
